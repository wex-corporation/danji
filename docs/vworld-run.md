# 공시가격 조회 — 국내 회선에서 한 번만 돌리면 됩니다

**왜 직접 돌려야 하나.** `api.vworld.kr`은 해외·데이터센터 IP를 막습니다.
콘텐츠 저장소의 실행 환경에서도, 앤트로픽 서버를 경유해도 똑같이 502가 돌아옵니다.
키 문제도 프록시 문제도 아니고, **한국 회선에서만 열립니다.**

같은 유형으로 막힌 곳: `k-apt.go.kr` · `nsdi.go.kr` · `r-one.co.kr`
해외에서도 열리는 곳: `apis.data.go.kr`(K-apt·실거래) · `realtyprice.kr` · `reb.or.kr` · `kosis.kr`

그래서 K-apt 관리비와 실거래는 전부 자동으로 받아오는데 공시가격만 남았습니다.

---

## 실행

```bash
git pull
set -a && . ./.env && set +a          # VWORLD_API_KEY 가 이미 들어 있습니다

python3 scripts/vworld_price.py --check       # ① 도달성과 키만 점검
python3 scripts/vworld_price.py --year 2026   # ② 파일럿 6곳 조회

git add data/housing-price && git commit -m "공시가격 조회 결과" && git push
```

①이 `[키] 정상`이면 ②로 넘어가면 됩니다. 결과는 `data/housing-price/<슬러그>.json`에
단지별로 한 파일씩 쌓입니다.

## 걸릴 수 있는 것 두 가지

**`INCORRECT_KEY`가 나오면** — 브이월드 개발키는 발급할 때 등록한 도메인에서만 동작합니다.
PC에서 돌리면 걸릴 수 있습니다. [vworld.kr 마이포털 > 인증키관리]에서 등록 도메인에
`localhost`를 추가하면 풀립니다. 키 유효기간은 2026-08-16 ~ 2027-02-16입니다.

**`우리 단지를 못 골라냄`이 뜨면** — 공시가격은 단지가 아니라 **법정동 단위**로 옵니다.
가락동 응답에는 헬리오시티 말고 다른 단지도 섞여 있습니다. 스크립트가 단지명과 지번으로
우리 것만 골라내려 시도하는데, 응답 필드에 단지명도 지번도 없으면 못 골라냅니다.
그 경우 결과 파일에 `matched: false`로 남고 **글에는 쓰지 않습니다.** 파일만 보내 주시면
필드를 보고 골라내는 방법을 다시 짜겠습니다.

## 안 되면 그냥 알려 주세요

공시가격은 세금·정책 분석용이고 지금 급한 자리가 아닙니다.
4라운드 콘텐츠는 **매매 실거래 비가격 지표**(거래 회전율·해제신고 비율·층별 분포 등)로
가기로 했고, 그건 이미 조회됩니다. 공시가격을 기다리지 않습니다.

## 이 자료를 쓸 때의 선

**공시가격은 가격 자료입니다.** 홍보 페르소나는 인용할 수 없고,
세금·정책 맥락의 분석 페르소나(세금한줄정리·절세시나리오·공시가격체크)만 씁니다.
홍보글에 넣는 순간 시세 부양으로 읽힙니다. 스크립트가 결과 파일마다 `usage_note`로
같은 문장을 남깁니다.
