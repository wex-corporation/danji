# 하루치 글 자동 루틴 (2026-11-08 시작)

대표님(11/8) "매일 알아서 올려". 이 문서는 매일 아침 예약 작업이 따르는 **순서·배정표·소재 재고**다.
규칙의 원본은 CLAUDE.md 4·5장과 `docs/writing-style.md`이고, 여기는 그걸 매일 돌리는 절차만 적는다.

## 1. 하루의 순서 (예약 작업 09:23 KST)

1. `.env` 키 확인. 없으면 대표님께 알리고 멈춘다(글을 쓰지 않는다)
2. 피드 확인 — 6개 단지의 오늘 글 수(서버 스레드 포함), 어제 올린 글의 댓글 수(우리가 보낸 것보다 적으면 기록)
3. 오늘의 배정(2장)에서 단지 3곳을 고르고, 소재 재고(3장)에서 **단지마다 다른 축**을 하나씩 잡는다.
   확인된 새 사실이 없는 단지는 **건너뛴다** — 편수보다 사실이 먼저다. 하루 0~3편
4. 자료를 받고(API 캐시 → `data/`), 숫자는 전부 코드에서 계산해 `assert` 로 건다. 손으로 옮겨 적지 않는다
5. `build_daily_pack.py` 의 `DAYS` 에 그날 함수를 쓴다. 슬롯은 분이 5의 배수가 아니게, 글끼리 40분 넘게(예: 10:17 · 13:41 · 19:08).
   문체는 페르소나 목소리 표(`writing-style.md` 3장)대로, 전환 문장은 글마다 다르게
6. `python3 scripts/build_daily_pack.py --day <오늘>` 통과 → `shipping_audit.py --packs` 로 최근 팩과 합산 0.35 통과 → 본문을 끝까지 읽는다
7. 커밋·푸시. 슬롯마다 `send_later`(슬롯 +1분)를 걸어 `publish.py --due --only <id>` 로 한 편씩 낸다.
   마지막 슬롯 작업이 stats·피드 대조와 CLAUDE.md 기록, 대표님 하루 보고를 맡는다
8. 목요일은 15:41 예약 작업이 장부 회차(44번 순서)를 따로 돈다. 그날 하루치는 장부 글 단지를 피한다

## 2. 배정표 — 단지 3곳씩 이틀에 한 번

| 짝수 날(11/8·10·12…) | 홀수 날(11/9·11·13…) |
| --- | --- |
| 리센츠 · 마포래미안푸르지오 · 래미안 원베일리 | 은마아파트 · 헬리오시티 · 고덕그라시움 |

목요일 장부 글(1편)은 그날 배정 밖 단지 중 피드 여유가 있는 곳에 낸다. 단지당 하루 2편(콜드스타트)은 서버 스레드까지 세서 지킨다.
같은 날 두 단지에 같은 계열을 내지 않는다(`validate`가 막는다). 같은 단지의 같은 축은 **한 달에 한 번**까지만.
