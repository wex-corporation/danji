# 단지광장 자료 수집 요청 (2026-10-25)

## 배경
단지광장(https://danji.life)은 서울 아파트 6개 단지에 AI가 공공자료로 글을 쓰는 커뮤니티다.
글을 쓰는 콘텐츠 에이전트는 해외 클라우드에서 돈다. 그래서 국내 회선에서만 열리는 사이트를 못 읽는다.
게다가 컨테이너가 다시 만들어질 때마다 API 키가 사라진다.
당신에게 맡기는 일은 **글쓰기가 아니라 자료와 접근 경로를 확보하는 것**이다.
글은 콘텐츠 에이전트가 검사를 거쳐 쓴다.

대상 단지 6곳:

| 단지 | 구 | 법정동코드 | K-apt 단지코드 |
| --- | --- | --- | --- |
| 래미안 원베일리 | 서초구 반포동 | 1165010700 | A10023043 |
| 은마아파트 | 강남구 대치동 | 1168010600 | A13583507 |
| 헬리오시티 | 송파구 가락동 | 1171010700 | A10025850 |
| 리센츠 | 송파구 잠실동 | 1171010100 | A13822003 |

| 마포래미안푸르지오 | 마포구 | **미확정** | A12175203 |

**법정동코드는 손으로 적거나 추정하지 않는다.** 예전에 손으로 적은 값이 6곳 중 4곳 틀렸고, 틀려도 조회는 성공해서 엉뚱한 동의 값이 저장됐다.
미확정 두 곳은 아래 둘 중 하나로 확정하고, 어디서 확인했는지 남긴다.
- 행정표준코드관리시스템(code.go.kr)
- 국토교통부 아파트 매매 실거래 응답의 `sggCd`+`umdCd`

## 과제 1 — 공공데이터포털 활용신청 (대표님 계정)
아래 API를 data.go.kr에서 활용신청한다. 주소는 `https://www.data.go.kr/data/{번호}/openapi.do`이다.
- 신청 전에 각 페이지에서 **승인방식(자동/심의)과 이용허락범위**를 원문으로 확인하고 표에 적는다
- 아래 '예상' 칸은 제3자 색인을 보고 적은 값이라 원문과 다를 수 있다

| 우선 | 번호 | 이름 | 예상 |
| --- | --- | --- | --- |
| 1 | 15012964 | 국토교통부_공동주택 에너지 사용 정보 | 자동 · 제한 없음 |
| 1 | 15150945 | 한국승강기안전공단_건물별승강기정보 조회 | 자동 · **출처표시** |
| 1 | 15151161 | 한국승강기안전공단_승강기안전검사이력 조회 | 자동 · 제한 없음 |

| 2 | 15059469 | 국토교통부_공동주택관리비(개별사용료) | 자동 · 제한 없음 |

승인되면 API마다 **단지 하나로 시험 호출**하고 응답 원문(JSON/XML)을 저장한다.
- 시험할 단지: 헬리오시티. 단지코드가 들어가는 API는 A10025850, 법정동코드가 들어가는 API는 1171010700
- 저장 파일에 **키가 들어가지 않게** 요청 URL에서 serviceKey를 지운다
- 오류 코드가 나오면 그대로 적는다

## 과제 2 — 브이월드 공동주택가격 (국내 회선 전용)
- 엔드포인트: `https://api.vworld.kr/ned/data/getApartHousingPriceAttr`
- 파라미터: `key`(대표님 브이월드 키), `format=json`, `numOfRows=100`, `pageNo`, `ldCode`(법정동코드 10자리), `stdrYear=2026`
- 응답은 단지가 아니라 **법정동 단위**다. 다른 단지가 섞여 온다
- 6곳의 법정동마다 마지막 페이지까지 받아 원문을 단지별 파일로 저장한다
- 우리 단지 행만 골라내려 하지 말고 원문 전체를 보낸다. 골라내는 건 콘텐츠 쪽에서 필드를 보고 한다
- `INCORRECT_KEY`가 나오면 브이월드 마이포털 > 인증키관리에서 등록 도메인에 `localhost`를 추가한다
- 키 유효기간은 2027-02-16까지다

## 과제 3 — 한국부동산원 주간 아파트 가격동향 (9/24 이후 발표분 전부)
- 원문 보도자료(PDF·HWP)를 내려받는다
- 아래 지역의 **매매·전세 변동률**을 표로 옮긴다: 서울 전체 · 서초구 · 강남구 · 송파구 · 강동구 · 마포구
- CSV 열: `발표일, 조사기준일, 지역, 매매변동률(%), 전세변동률(%), 원문URL, 확인일`
- 표에 없는 값은 빈칸으로 둔다. 앞뒤 주로 채우거나 추정하지 않는다

## 과제 4 — 참가격 '서울(강남)'의 범위 확인
- 한국소비자원 참가격 > 결혼서비스 > 지역별 가격정보는 '서울(강남)'과 '서울(강남외)'로 나뉜다
- **'서울(강남)'이 강남구만인지, 강남·서초·송파 등 여러 구인지** 공식 설명을 찾는다(조사 방법, 자주 묻는 질문, 공지)
- 찾으면 그 문장을 그대로 옮기고 URL과 확인일을 붙인다
- 사이트에서 못 찾으면 못 찾았다고 보고한다. 기관에 전화하거나 문의 글을 남기는 건 대표님 승인을 받은 뒤에만 한다

## 과제 5 — 키 재전달 (대표님께만)
- 공공데이터포털 일반 인증키(Decoding 값) 1개. 기존 관리비·실거래 API와 과제 1의 API가 모두 이 키를 쓴다
- 게시 키(`CIVIC_PULSE_API_KEY`)는 서버 담당(CTO)에게 받는다. 9/27에 발급된 키가 그대로 유효한지 확인한다
- 키는 **대표님께 직접 1:1로만** 전달한다. 슬랙 채널, 드라이브, 결과 파일에 절대 적지 않는다

## 지킬 것
- **확인 못 한 값은 만들지 않는다.** 실패하면 실패했다고 쓰고 무엇을 시도했는지 적는다
- 모든 숫자에 원문 URL과 확인일을 붙인다
- 호가(네이버 부동산 등)와 커뮤니티 후기(호갱노노·블라인드·당근 등)는 수집하지 않는다. 판례와 운영 명세로 금지된 영역이다
- 성범죄자 공개 정보는 어떤 형태로도 다루지 않는다
- 단지광장에 글이나 댓글을 직접 올리지 않는다
- 사람이 판단해야 할 일(유료 신청, 기관 문의, 약관 동의)은 진행 전에 대표님께 묻는다

# 단지광장 자료 수집 2차 (2026-10-26)

1차 수집 고맙다. 전부 원문 대조를 통과했다. 남은 일은 셋이다. **①과 ③은 대표님이 "진행"이라고 하신 뒤에만 한다.**

## ① 신규 API 4개 활용신청 (대표님 승인 후)
- 대상: 15150945(건물별 승강기정보, 출처표시) · 15151161(승강기 안전검사이력) · 15151169((신)승강기 사고·고장이력) · 15012966(회계감사보고서)
- 로그인은 대표님이 네이버 QR을 직접 찍어 주시는 방식으로만 한다. 로그인 시도를 반복하지 않는다
- 승인되면 **마이페이지에 나오는 정확한 요청주소**를 적는다. 1차 때 회계감사 주소를 추정해서 불렀다가 NO_OPENAPI_SERVICE가 났다
- 헬리오시티로 시험 호출하고 원문을 저장한다(serviceKey 제거)
  - 승강기 API: 주소·건물관리번호 등 요구하는 파라미터를 그대로 적는다
  - 회계감사: kaptCode A10025850
- 참고: K-apt API 버전이 바뀌었다. 기본정보는 `AptBasisInfoServiceV5`(getAphusBassInfoV5·getAphusDtlInfoV5), 공용관리비는 `AptCmnuseManageCostServiceV3`다. 1차 때 V4로 불러 실패한 건 이 때문이다

## ② 브이월드 공동주택가격 (키를 받으면)
- 1차 과제 2와 같다. 법정동코드 6곳은 1차에서 확정한 값을 쓴다
- 키는 대표님이 직접 주신다. 받은 키는 파일에 적지 않는다

## ③ 서버 담당(CTO)에게 확인할 것 (대표님 승인 후)
대표님이 맡기시면 아래 넷을 한 번에 묻는다. 답은 원문 그대로 옮긴다.
1. 9/27에 발급한 게시 키(`ingest:write`)가 아직 유효한가. 아니면 재발급을 부탁드린다(키는 대표님께 1:1로)
2. 9월 말부터 글 페이지가 전부 `noindex`이고 사이트맵에 글이 없다. 의도한 변경인가
3. 9월에 단지 5곳(올림픽파크 포레온·파크리오·잠실엘스·아크로리버파크·디에이치 퍼스티어)과 댓글 약 500개가 사라졌다. 원인이 무엇인가
4. 글 상세 API(`/api/v1/posts/{id}`)가 호출마다 조회수를 올린다. 콘텐츠 에이전트(User-Agent `danji-content-agent/1.0`) 조회는 빼 줄 수 있는가
