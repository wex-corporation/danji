# 생활환경 자료 축 + 상시 관측소 — 대표님용 요약과 비서용 프롬프트 (2026-11-01)

대표님 요청(11/1): "에이전트들이 더 풍부한 글을 쓰게 공개 API를 더 붙이고 싶다. 주변 학교·학원·스터디카페·병원·학생 수·
단지 대비 학교 수 같은 걸 분석할 기초 자료, 그리고 이걸 실시간으로 계속 연구하는 시스템. 비서에게 전체를 붙일 프롬프트."

1~4장은 대표님이 읽는 요약이고, 5장 구분선 사이가 비서(맥 미니, 국내 회선)에게 그대로 붙여 넣는 프롬프트다.
6장은 받은 뒤 콘텐츠 쪽에서 할 일이다.

---

## 1. 결론

- **붙일 만한 공개 자료를 27개 찾았다.** 절반은 지금 쓰는 공공데이터포털 키에 **활용신청만 더 하면** 된다(대부분 자동승인).
  새 키가 필요한 곳은 나이스(NEIS)·학교알리미·도로명주소 좌표·도서관정보나루·서울 열린데이터광장·SGIS 등 별도 포털이다.
- **학원·독서실은 나이스로 바로 된다.** 키 없이 시험 호출해 보니 송파구에만 학원·교습소가 1,985곳 등록돼 있고 그중 독서실이 37곳이다(11/1).
  주소·교습계열·정원·개설일·등록상태(개원/휴원/폐원)가 나온다. **스터디카페는 등록 업종이 아니라 나이스에 없다** — 소상공인 상가(상권)정보로 센다.
- **서울대 진학률은 붙이지 않기를 권한다.** 학교 단위 공식 출처가 없고, 우리 규칙(학교·학군 서열 금지)과 정면으로 부딪힌다(3장).
- **상시 관측 시스템은 만들 수 있다.** 다만 '실시간'은 출처마다 다르다. 진짜 실시간은 도서관 열람실 좌석 정도이고,
  학원 등록은 매일, 인구·승하차는 매월, 학교·학급은 학년도마다 바뀐다. **출처별 주기로 돌면서 '바뀐 것'을 찾아 글감 큐로 넘기는 구조**가 맞다(4장).
- 관측소의 본체는 **맥 미니 비서**가 맡는 게 맞다. 국내 회선이고, 꺼지지 않고, 키가 사라지지 않는다.
  이 콘텐츠 에이전트의 컨테이너는 키가 두 번 사라졌다(CLAUDE.md 28·39번).

## 3. 서울대 진학률 — 권하지 않는 이유와 대안

1. **학교 단위 공식 출처가 없다(내가 아는 범위).** 학교알리미 '졸업생 진로 현황'은 대학 진학자 수 합계(4년제·전문대 등)뿐이고 대학별이 아니다.
   고교별 서울대 합격자 수는 해마다 국회의원실 요청 자료가 언론에 실리는 형태다. 2차 출처이고, 수시·정시·재수생 포함 여부가 기사마다 다르다.
   비서에게는 **공식 1차 출처가 있는지 확인만** 시킨다(5장 과제 6). 기사·학원가 자료·입시 커뮤니티는 수집하지 않는다.
2. **우리 규칙과 정면으로 부딪힌다.** 학교·학군 서열 어휘 금지, 단지 간 우열 비교 금지(CLAUDE.md 5장). '학군갈아타기' 페르소나를 깨우지 않은 이유가 이것이다.
   진학 실적은 그 자체가 서열이고, 단지 글에 붙는 순간 가격 신호로 읽힌다. 홍보 페르소나가 가격을 말하면 안 되는 것과 같은 선이다.
3. **붙이려면 먼저 운영 명세를 바꿔야 한다.** 명세 v1.2에서 학교 서열 규칙을 다시 정하고 법률 검토를 거친 뒤에 할 일이지, 수집부터 할 일은 아니다.

대안 — 서열 없이 '주거환경'을 보여 주는 학교 지표:
배정 학교까지 거리(학구도 + 좌표) · 학급 수 변화(나이스) · 학급당 학생 수(학교알리미 원문 인용) · 개교 연도 ·
학원 개원·폐원 흐름 · 독서실·스터디카페 수 · 도서관 열람실 · 학령인구(통반·집계구) · 등굣길 사고다발지 · 밤에 여는 소아과.

## 4. 상시 관측소 — 구조

```
[수집]  출처별 주기로 받는다
        ├─ 해외에서도 되는 것: 공공데이터포털·나이스·도로명주소 좌표
        └─ 국내 회선 전용: 서울 열린데이터광장·어린이집·생활안전지도·브이월드
           → 둘 다 맥 미니가 돈다(꺼지지 않고, 키가 남는다)
[저장]  danji-env/<출처>/<날짜>.json  — 스냅숏. 키 제거, 개인정보 칸 삭제, 이용허락 등급 표시
[변화]  지난 스냅숏과 비교 → 사건: 학원 개원·폐원 · 의원 개업·폐업 · 학급 수 변화 · 학령인구 변화 · 인기 대출 도서 교체
[발견]  data/findings/<날짜>.json  — 사실 한 문장 + 출처 + 확인일 + 쓸 수 있는 페르소나 + 이용허락 등급
[글]    build_daily_pack 이 발견 큐에서 고른다 → 자체 검사·출고 검사 → 대표님 승인 → 게시
```

| 주기 | 출처 |
| --- | --- |
| 실시간(필요할 때만) | 도서관 열람실 좌석 |
| 매일 새벽 | 나이스 학원교습소(등록상태·개설일), 의원·병원·약국 인허가 |
| 매주 | 상가(상권)정보 |
| 매월 | 주민등록 인구, 역별 승하차, 병·의원 진료시간 |
| 학년도마다 | 학교기본정보, 학급정보, 학구도, 학교알리미 공시 |
| 해마다 | 브이월드 공동주택가격 |

가드레일(수집 단계에서 막는다):
- **이용허락 등급을 스냅숏에 박는다.** '변경금지'는 원문 숫자 인용만 허용하고 비율·순위 가공을 막는다(에어코리아와 같은 처리, CLAUDE.md 38번)
- **개인정보 칸은 저장하지 않는다.** 나이스 학원 자료의 전화번호 칸에 개인 휴대전화(010)가 섞여 있다. 받는 즉시 지운다
- 글에는 **개별 학원·병원 이름을 쓰지 않는다**(특정 업체 홍보·폄하 소지). 수와 구성만 쓴다. 학교 이름은 공공기관이라 쓸 수 있다
- 교습비는 집값이 아니지만 돈이다. 홍보 페르소나는 쓰지 않고, 분석 페르소나만 기준을 붙여 쓴다
- 요청은 초당 1회 미만, 심야. 429·캡차가 나오면 그 출처를 멈춘다. 차단 회피는 어떤 경우에도 하지 않는다(명세 9.6.4)

지금까지는 관리비·실거래·부동산원 주간 동향으로 썼다. 대표님이 **단지 주변 주거환경**(학교·학원·독서실·스터디카페·병원·
아이 인구·통학 안전) 자료를 붙이라고 하셨고, 그걸 **계속 지켜보는 상시 수집**도 원하신다.
당신이 맡을 일은 **자료와 접근 경로를 확보하고, 국내 회선에서 꾸준히 받아 오는 것**이다. 글은 콘텐츠 에이전트가 검사를 거쳐 쓴다.

대상 단지 6곳(법정동코드는 실거래 응답으로 확정한 값이다. 손으로 고치지 않는다):

## 과제 5 — 학교알리미 '변경금지'의 범위
- 공공데이터포털 원문 기준 학교알리미 공시정보는 **공공누리 제3유형(출처표시·변경금지)** 이다
- 학교알리미 이용약관·공공누리 안내에서 **숫자를 원문 그대로 인용하는 것과, 그 숫자로 비율을 계산하는 것이 각각 허용되는지** 판단할 문장을 찾아 그대로 옮긴다
- 같은 학생 수를 이용조건이 넓은 다른 공식 출처(예: 교육통계서비스 kess.kedi.re.kr 학교별 자료)에서 받을 수 있는지와 그 이용조건도 확인한다
- 판단은 하지 않는다. 문장과 출처만 가져온다

## 과제 6 — 서울대 진학 실적 (확인만)
- 고등학교별 서울대 합격·진학 자료가 **공식 1차 출처**(서울대학교, 교육부, 학교알리미 공시)에 있는지만 확인해 보고한다
- 언론 기사, 학원가 자료, 입시 커뮤니티는 수집하지 않는다. 공식 자료가 있어도 **내려받지 않는다** — 쓸지 말지는 대표님이 운영 규칙과 함께 정하신다

## 과제 7 — 상시 관측소 (대표님 승인 후 설치)
맥 미니에 주기 수집 작업을 설치한다(launchd 또는 cron). 설치 전 아래 계획을 대표님께 보여 드리고 "진행"을 받는다.

수집 주기:
| 주기 | 대상 |
| --- | --- |
| 매일 03:00 | 나이스 학원교습소정보(6개 단지의 구 전체), 의원·병원·약국 인허가(6개 구) |
| 매주 월 03:30 | 상가(상권)정보(6개 단지 좌표 반경 1km) |
| 매월 2일 04:00 | 통반 성·연령별 인구, 역별 승하차, 병·의원 찾기(진료시간), 서울시 생활인구·상권분석 |
| 매년 3월·9월 | 학교기본정보, 학급정보, 학교알리미 공시, 학구도 6건 |

저장 형식(출처마다 한 파일, 날짜별로 쌓는다):
```
danji-env/<출처>/<YYYY-MM-DD>.json
{
  "source": "나이스 학원교습소정보",
  "endpoint": "https://open.neis.go.kr/hub/acaInsTiInfo",   ← 키 없는 주소
  "query": {"ATPT_OFCDC_SC_CODE": "B10", "ADMST_ZONE_NM": "송파구"},
  "license": "원문 문장 그대로",
  "fetched_at": "2026-11-02T03:00:12+09:00",
  "total_count": 1985,
  "pages": 2,
  "dropped_fields": ["FA_TELNO"],
  "rows": [ ... 원문 그대로, 지운 칸만 빼고 ... ]
}
danji-env/_log/<YYYY-MM-DD>.md   성공·실패·상태코드·건수
```
- **원문을 고르거나 고치지 않는다.** 단지 반경으로 골라내는 것도 콘텐츠 쪽에서 한다. 받은 그대로(지운 칸만 빼고) 둔다
- `total_count`와 받은 행 수가 다르면 실패로 적는다(페이지를 끝까지 돌지 않으면 앞부분만 남는다)
- 요청은 초당 1회 미만. 429·캡차·차단 응답이 나오면 그 출처를 멈추고 로그에 남긴다. 프록시·우회는 쓰지 않는다
- 키는 맥 미니 안(키체인 또는 로컬 `.env`)에만 둔다. 드라이브·슬랙·결과 파일·로그에 키가 들어가지 않게, 저장 전에 키 문자열을 검사한다
- 매주 월요일 아침 `_log`를 요약해 대표님께 한 줄로 보고한다(성공 출처 수 · 실패 출처 · 새로 쌓인 파일 수)

## 키 전달
- 새로 발급된 키는 **대표님께 직접 1:1로만** 전달한다. 슬랙 채널, 드라이브, 결과 파일, 로그에 절대 적지 않는다
- 공공데이터포털은 기존 일반 인증키를 그대로 쓰므로 다시 전달할 필요가 없다

## 지킬 것
- **확인 못 한 값은 만들지 않는다.** 실패하면 실패했다고 쓰고 무엇을 시도했는지 적는다
- 모든 숫자에 원문 URL과 확인일을 붙인다
- 개인정보(전화번호, 원장·대표자 이름 같은 개인 이름)는 저장하지 않는다
- 학교·학원·병원에 순위나 '좋다/나쁘다'를 매기지 않는다. 결과 요약에도 쓰지 않는다
- 호가(네이버 부동산 등)와 커뮤니티 후기(호갱노노·블라인드·당근·맘카페 등)는 수집하지 않는다
- 성범죄자 공개 정보는 어떤 형태로도 다루지 않는다
- 단지광장에 글이나 댓글을 직접 올리지 않는다
- 사람이 판단해야 할 일(회원가입, 약관 동의, 유료 신청, 기관 문의, 상시 수집 설치)은 진행 전에 대표님께 묻는다

- **원문 대조부터.** 비서가 보낸 표·샘플을 이 환경에서 다시 호출할 수 있는 것은 다시 불러 맞춘다(1차·2차 때와 같은 방식)
- `data/geo.json` — 6개 단지 좌표·행정동·통반·집계구. 도로명주소 좌표 API 응답에서 뽑는다(손으로 적지 않는다)
- `scripts/env_*.py` — 해외에서도 되는 출처(공공데이터포털·나이스·도로명주소)는 콘텐츠 쪽에도 수집기를 둔다. 맥 미니가 멈췄을 때의 예비이자 대조용이다
- `scripts/env_watch.py` — 스냅숏 두 장을 비교해 사건을 뽑고 `data/findings/<날짜>.json`에 쌓는다. 항목마다 이용허락 등급과 쓸 수 있는 페르소나를 붙인다
- `build_daily_pack.py` — 발견 큐에서 그날 소재를 고른다. 새 검사: 전화번호 패턴 금지, 개별 학원·병원 이름 금지, '변경금지' 출처의 비율·순위 금지, 학교 서열 어휘(기존)
- 첫 글 후보(자료가 오면 숫자를 채운다):
  은마 — 대치동에 올해 새로 등록된 학원·교습소 수와 폐원 수 · 헬리오 — 단지 안 어린이놀이시설과 마지막 안전검사일 ·
