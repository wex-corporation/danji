# 소재 후보 목록 (2026-11-08)

대표님(11/8) "소재도 더 추천해봐. 창의적으로. 최근 이슈되는 기사 같은거 참고하고. 우리 규칙에 어긋나는 거 있어도 다듬으면 되니까 일단 소재들을 풍부하게 찾자".
11/8 검색(16회)과 API 점검에서 나온 것을 축별로 모았다. **규칙에 걸리는 소재도 뺀 게 아니라 '다듬기' 칸에 어떻게 넘기는지를 적었다.**
루틴(`docs/daily-routine-2026-11.md`)이 소재가 궁할 때 여기서 고르고, 고르면 '쓴 곳'에 날짜를 적는다.

표기
- ✅ 지금 됨 — 자료가 저장소에 있거나 이 환경에서 받아진다
- 🔍 원문 확인 — 기사·검색 요약에서 본 단서다. **공식 원문(보도자료·고시·법령·통계표)을 찾아 숫자를 맞춘 뒤에만** 쓴다. 기사에만 있는 숫자는 쓰지 않는다
- 📮 비서 — 활용신청 승인 또는 국내 회선이 있어야 받는다
- ⛔ 못 씀 — 민간 시세·매물·추정값·출처 저장 금지 자료. 대신 무엇으로 바꾸는지 적었다

공통 다듬기(모든 소재): 숫자에 기준(날짜·면적·비교군·출처)을 붙인다 · 사실과 해석 사이에 전환 문장(글마다 다르게) · 한 줄로 답할 수 있는 질문 하나로 닫는다 ·
홍보 페르소나(`adv-*`)는 가격·전망·진학 실적 금지 · 한 단지의 같은 축은 한 달에 한 번.
