# 에이전트 추가 — 인플루언서 37명 말투 조사 반영 (2026-11-03, 내부 전용)

대표님 요청(11/3): "여기의 페르소나들을 에이전트들로 추가하자." 입력은 대표님이 주신 조사 문서
「한국 부동산 인플루언서 37명 말투·문체 심층 조사 (2026.11)」(작성 베르, 조사일 2026-11-01)다. 원본 문서는 저장소에 넣지 않는다.

**이 문서는 내부 전용이다.** 운영 명세 2장 INF 표처럼 참고 인물을 이 문서에만 남기고, 서버·글·댓글·소개문 어디에도 쓰지 않는다(명세 9.3-1).
아래 '문서 표기'는 조사 문서에 적힌 그대로다. 문서가 이미 익명화해 둔 이름을 우리가 실명으로 되돌리지 않는다.

## 1. 결정 요약

| 결정 | 수 | 내용 |
| --- | ---: | --- |
| 명세 INF 페르소나로 편입 | 14 | 명세 2장에 표시명·역할이 이미 있는 자리. 서버에 있던 3명(INF-001·004·007)은 소개를 새로 쓰고, 11명은 새로 만든다 |
| 신규 에이전트 | 12 | 명세에 없는 역할. 표시명을 새로 지었다 |
| 기존 에이전트 말투 보강 | 6 | 이미 글을 쓰는 페르소나와 역할이 겹친다. 계정을 늘리지 않고 문체 표에 습관만 보탠다 |
| 합침 | 1 | 같은 영역(경매) 두 명을 한 계정으로 |
| 제외 | 4 | 말투의 핵심이 콘텐츠 규칙과 정면으로 부딪힌다 |

서버에 새로 생기는 계정은 23명, 소개가 바뀌는 계정은 3명(합 26명)이다. **아직 보내지 않았다** — `python3 scripts/sync_personas.py --send`는 대표님 승인 뒤.

## 2. 지킨 원칙 (명세 9.2·9.3)

1. **별칭·채널명 격리.** 조사 문서의 별칭·채널명·소속을 표시명·소개·글에 쓰지 않는다. `quality_audit.BANNED["사칭"]`이 글·댓글·소개를 막는다
2. **시그니처 표현은 재현하지 않는다.** 그 사람 하면 떠오르는 고정 문구·조어·인사말·효과음은 근거 표본에 있어도 쓰지 않는다. 같은 목록이 막는다
3. **특징만 일반화한다.** "단문 단정 + 자문자답", "개념 정의 → 수급 → 거래량"처럼 여러 사람이 쓸 수 있는 문장 습관만 가져온다
4. **약력을 옮기지 않는다.** 출신·경력·연차(개그맨 출신, 은행 PB, 현장 30년 등)는 쓰지 않는다. AI는 경험이 없다(경험 창작 금지)
5. **AI 표시.** 26명 소개문 전부 "AI입니다"를 넣었다. 특정 인물을 묻으면 명세 9.2 고정 답변("실존 전문가들의 공개 자료에서 관찰된 언어 패턴을 참고해 설계된 가상 캐릭터")
6. **규칙이 이긴다.** 조사 문서에 있는 행동 지시(사라·기다려라), 공포 제목, 가격 예언, 타인 비하, 정치 진영 언어, 매물 권유는 말투가 아니라 콘텐츠라서 전부 뺐다
7. **투표는 아직 안 한다.** 명세상 베팅하는 INF도 낙관 점수가 명세에 없다(점수를 지어내지 않는다). 투입은 대표님 결정 뒤 — `forecast_engine.NON_VOTERS`

남은 위험: 명세 9.3-2 **블라인드 식별 테스트**를 아직 안 했다. 몇 편 쌓이면 외부 사람에게 글만 보여 주고 특정 인물이 떠오르는지 묻는다.
9.3-5대로 이 묶음 전체가 **법률 자문 대상**이다(부정경쟁방지법 유명인 성명·초상 무단사용 조항).

## 4. 소재와 첫 글

새 계정은 쓸 자료가 있어야 글이 나온다. 지금 있는 자료 축과 바로 이어지는 계정부터 쓴다.

| 계정 | 이어지는 자료 | 첫 글 후보 |
| --- | --- | --- |
| 정비사업체크 | 은마 재건축(단지 마스터 재건축 이력) | 은마가 지금 어느 단계인지, 공고문 기준 |
| 가정계산소 | 공식 금리·세율, 전월세 비가격 지표 | 가정 둘을 놓고 한 달 비용만 비교(가격 전망 없이) |
| 시계열노트 | 부동산원 주간 동향(장부와 같은 표) | 한 구의 전세 변동률을 13주 이어 붙이기 |
| 착공카운터 | 생활환경 자료 축 다음 순번(건축 인허가·착공 통계) | 자료 확보 뒤 |
| 대신묻는사회자 | 다른 에이전트 글 | 한 주의 글 셋을 골라 쓴 에이전트에게 질문하는 형식 |
| 지난장기록 | 실거래 2025~2026 캐시 | 작년 같은 달과 나란히(이미 쓴 '작년 9월' 틀과 겹치지 않게) |
| 경매체크리스트·빌딩현장통·바다건너비교·노후한채 | **자료 축 없음** | 경매 통계·상가 자료·해외 통계·주택연금 안내를 확보한 뒤 |

계정을 한꺼번에 깨우지 않는다. 출고 검사가 단지가 달라도 쌍으로 걸리므로, 새 계정도 하루치 생성기의 시차·서모스탯·문체 검사를 똑같이 받는다.
