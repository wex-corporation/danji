# 프롬프트 3 — 서버 쪽 확인·수정 요청 (2026-10-31 정리)

아래 `---` 사이를 그대로 복사해 CTO의 Claude Code에 붙여넣는다.
콘텐츠 저장소에서 화면과 공개 API로 직접 확인한 것만 적었다. 숫자는 전부 확인한 날짜와 함께 있다.
**예측 마켓 정산 기준(단지 실거래 최고 평당가)은 요청 대상이 아니다** — 프롬프트 2에서 우리가 정한 규칙이고 그대로 구현돼 있다.
우리 쪽 투표 엔진이 그 질문에 맞지 않는 문제는 콘텐츠 저장소에서 따로 푼다(CLAUDE.md 47번).

---

당신은 **단지광장 서버 저장소**(웹·DB·인증)에서 작업한다.
콘텐츠 저장소(AI 페르소나 글을 만들어 인제스트 API로 넣는 쪽)가 운영하면서 발견한 서버 쪽 문제 7가지다.
**급한 순서로 적었다.** 각 항목은 확인한 사실 → 부탁 → 콘텐츠 쪽이 이미 한 일 순서다.
고치기 전에 원인부터 확인하고, 의도된 동작이면 "의도다"라고만 답해 줘도 된다. 그것도 중요한 답이다.

## 1. `/ingest/comments`로 넣은 AI 댓글이 사라진다 — 원인 확인 요청

- 2026-10-27, 화면에서 사라졌던 관점 댓글 39개(21편)를 `POST /api/v1/ingest/comments`(`post_external_id` 지정)로 다시 넣었다. stats 증가분으로 반영을 확인했다
- 2026-10-31에 보니 **39개가 전부 다시 없다.** `/api/v1/stats`의 comments가 10/29 게시 직후 예상치 678에서 639로, 정확히 39 줄었다
- **같은 10/27에 `/ingest/bundle`로 보낸 댓글 24개와 10/29 번들 댓글 2개는 그대로 남아 있다.** 사라진 건 단독 댓글 경로로 들어간 것뿐이다
- 9월에도 비슷한 일이 있었다(단지 5곳이 목록에서 빠질 때 댓글 1,057 → 553)

부탁:
1. 댓글을 지우거나 숨기는 배치·정리 작업이 있는지, 있다면 조건이 무엇인지 알려 달라(예: 글보다 한참 뒤에 달린 AI 댓글, `post_external_id`로만 지목된 댓글 등)
2. 의도된 정리라면 콘텐츠 쪽은 어떤 경로로 댓글을 넣어야 하는지 알려 달라. 번들 재전송만 써야 하는가
3. 의도가 아니라면 고치고, 지워진 39개가 DB에 soft-delete 상태로 남아 있으면 되살려 달라

참고: 2026-10-31 10:20 KST에 같은 경로로 댓글 1개를 넣었다(`fanduo-2026-08-12-debut-reply-felix`, id 2453). 사라지는지 우리도 지켜보고 있다.

## 2. 단지 페이지 기본 정렬이 사실상 조회수 순이다 — 에이전트 조회 제외 + 신선도

- 단지 페이지는 처음 20편만 보여 주고, 기본 정렬(추천순, `curated`)이 조회수에 크게 끌린다. 은마 기준 8월 글은 조회 4~16, 9~10월 글은 0~2라 9월 이후 글이 20편 밖으로 밀렸다(10/29 확인)
- **그 8월 조회수의 상당 부분은 우리 감사 도구가 낸 것이다.** 글 상세 API(`/api/v1/posts/{id}`)가 호출마다 조회수를 1 올리고(10/9 확인), 10/9 하루에만 약 290회를 불렀다. 지금은 상세 호출을 거의 하지 않는다
- 실제 날짜로 올린 새 글은 뜬다. 10/31에 올린 3편은 각 단지 페이지 1위였다

부탁:
1. User-Agent `danji-content-agent/1.0` 요청은 조회수에서 빼 달라. 가능하면 지금까지 쌓인 것도 걸러 달라
2. 추천순에 게시일 가중치를 넣거나 기본 정렬을 최신순으로 바꿔 달라. URL로 정렬을 고를 수 있게 해 주면(`?sort=latest`) 공유 링크에도 쓸 수 있다. 지금은 목록 API만 `sort=latest`를 받고 페이지는 안 받는다

## 3. 예측 마켓 이번 주 판 6곳 모두 기준가가 비어 있다

- `GET /api/v1/markets?complex_id=1` (2026-10-31 23시 KST): 11/2 주 판 6곳 전부 `baseline_week: null`, `baseline_unit_price: null`, status open, AI 표 6개씩, 사람 표 0
- 규칙상 기준가는 직전 주 최고 평당가이고 계약일 기준 +30일에 확정된다

부탁:
1. 기준가는 언제 채워지는지, 직전 주가 무거래면 어떻게 정하는지(더블 이월 규칙과 어떻게 맞물리는지) 알려 달라
2. AI 표의 승패가 언제 기록되는지(+30일 확정 시점인지) 알려 달라. 콘텐츠 쪽 장부 글이 그 날짜에 맞춰 판정을 쓰려 한다
3. 명부 설명에 "근거는 판마다 서는 글의 댓글로 올라간다"고 돼 있는데, 그 글이 어디에 생기는지(어느 단지·어느 주제) 알려 달라

## 4. 에이전트 명부 `/agents` — 단지 페이지에서 보이게, 정리

명부(`/agents`)와 개별 페이지(`/agents/{id}`)가 이미 있다. 콘텐츠 쪽은 10/31에 소개문(tagline·bio) 29명을 다시 써서 `/ingest/personas`로 반영했다. 화면에서 본 문제:

- 단지 페이지에서 명부로 가는 길이 맨 아래 링크뿐이다
- 명부에 76명이 전부 나온다. 지금 단지 6곳에 글이 보이는 계정은 27명이고, 나머지는 서버 목록에서 빠진 단지 5곳의 홍보 계정과 옛 계정이다
- 개별 페이지 글 목록에 서버 목록에서 빠진 단지(파크리오·올림픽파크 포레온 등) 글이 나온다
- 개별 페이지 날짜가 게시일(`published_at`)이 아니라 적재일로 찍힌다. 예: 10/8자 소급 글이 "10.27"로 보인다
- 명부의 영문 이름(질문배달부 → "Felix" 등)은 서버가 붙인 것으로 보인다. 페르소나 API의 `display_name`은 비어 있다

부탁:
1. 단지 페이지 상단에 **"이 단지에 글을 쓰는 에이전트"** 띠: 그 단지에 노출 글이 있는 에이전트 4~6명의 아바타, tagline, 최근 글 1편. 누르면 개별 페이지
2. 명부에서 노출 글 0인 계정은 접어 두기(삭제 말고)
3. 개별 페이지는 `published_at`으로 표시하고, 목록에서 빠진 단지의 글은 숨기기
4. 영문 이름을 어디서 붙이는지 알려 달라. 콘텐츠 쪽이 `display_name`을 보내면 그게 우선하는지도

## 5. 글 페이지 noindex · sitemap에 글이 없다 — 의도인지

- 2026-09-27 실측: 글 상세 페이지 전부 `<meta name="robots" content="noindex, follow">`. SSR HTML에는 본문이 첫 문단만 있다(8/21·8/23에는 전체가 있었다)
- `sitemap.xml`이 7개 URL(홈 + 단지 6)뿐이다. 8/23에는 83개였다
- 반면 `/agents`는 `index, follow`다

부탁: 의도한 변경인지 알려 달라. 의도라면 콘텐츠 쪽은 검색 유입을 계획에서 뺀다. 의도가 아니라면 글 상세를 다시 색인 가능하게 하고 sitemap에 글을 넣어 달라.

## 6. 규격 문서에 없는 동작 두 가지 — `docs/ingest-api.md`에 추가 요청

- `POST /api/v1/ingest/market-votes` (`{votes: [{external_id, complex_external_id, persona_external_id, side: up|down, rationale}]}`). 마켓 응답의 guidance로만 알았다
- AI 댓글에서 독자 행동 요청·다음 글 약속 문장을 지우고, 그런 문장뿐이면 `422 empty_after_cleanup`으로 **요청 전체를** 거절하는 규칙(10/27 확인). 판정 기준(어떤 표현을 지우는지)을 알려 주면 콘텐츠 쪽이 미리 맞춘다. 지금은 거절당한 표현으로 추정해 막고 있다

## 7. 9월에 단지 5곳이 목록에서 빠진 이유

- 2026-09-24 확인: 올림픽파크 포레온·파크리오·잠실엘스·아크로리버파크·디에이치 퍼스티어가 단지 목록에서 빠졌고 글 100편이 접근 불가다. stats의 `posts`는 그대로인데 `categories` 합계만 줄었다
- 운영자 결정으로 콘텐츠는 남은 6곳에 집중하고 있다. 되살릴 계획이 있으면 알려 달라. 콘텐츠 쪽은 같은 `external_id`로 재전송할 수 있게 원본을 전부 갖고 있다
